# Система стилів: A5 навчальне видання з програмування

> Специфікація для генератора `md-to-docx`. Єдине джерело правди для всіх параметрів стилів.

---

## 1. Сторінка

| Параметр | Значення |
|---|---|
| Формат | A5 (148 × 210 мм) |
| Верхнє поле | 20 мм |
| Нижнє поле | 20 мм |
| Внутрішнє поле (для палітурки) | 25 мм |
| Зовнішнє поле | 15 мм |
| Дзеркальні поля | Так (для двостороннього друку) |
| Колонтитул зверху | Назва розділу (парна) / номер підрозділу (непарна) |
| Колонтитул знизу | Номер сторінки по центру |

**DXA-значення** (1440 DXA = 1 дюйм = 25.4 мм):
```
A5_W   = 8391   (148 мм)
A5_H   = 11906  (210 мм)
M_TOP  = 1134   (20 мм)
M_BOT  = 1134   (20 мм)
M_INN  = 1418   (25 мм — палітурна сторона)
M_OUT  = 851    (15 мм)
CW     = 6122   (ширина контенту = 108 мм)
```

## 2. Шрифтова база

| Роль | Шрифт | Обґрунтування |
|---|---|---|
| Основний текст | Times New Roman | Академічний стандарт, добра кирилиця, є скрізь |
| Заголовки | Times New Roman (та сама гарнітура) | Академічне видання не мікшує гарнітури |
| Код | Consolas | Найчитабельніший моноширинний для C# на Windows |
| Підписи | Times New Roman Italic | Підпис — варіант тіла, не окрема гарнітура |

**Розмір → half-points** (Word size = pt × 2):

| pt | half-pt | Де використовується |
|---|---|---|
| 18 | 36 | Назва розділу |
| 13 | 26 | Номерований підрозділ (1.1, 1.2…) |
| 11 | 22 | Тематичний підзаголовок (## без номера) |
| 10.5 | 21 | Основний текст, списки |
| 9.5 | 19 | Заголовки таблиць |
| 9 | 18 | Тіло таблиць, inline-код |
| 8.5 | 17 | Блок коду |
| 8 | 16 | Колонтитул, номер сторінки |
| 7.5 | 15 | Мітка мови (C# / Bash над блоком коду) |

## 4. Стилі абзаців

### 4.1 ChapterTitle — Назва розділу

```
ID:          ChapterTitle
Шрифт:       Times New Roman Bold, 18pt (#1A1A2E)
Вирівнювання: Ліворуч
Відступ:     0
Відстань до: 0pt; після: 18pt
Рамка:       знизу 2pt суцільна #0078D4 (синя риска)
Наступний:   ChapterIntro
Outline:     Level 1 (для змісту)
Розрив:      Немає (розрив сторінки — справа скрипту при збірці розділу)
```

**Вигляд:**
```
Розділ 1. Вступ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 4.7 BodyText — Основний текст

```
ID:          BodyText
Шрифт:       Times New Roman, 10.5pt (#1A1A1A)
Вирівнювання: По ширині
Відступ:     перший рядок 0.75 cm (425 DXA)
Міжрядковий: 1.15 (multiple = 276)
Відстань до: 0pt; після: 0pt
```

> Абзаци основного тексту НЕ мають відстані між собою — перший рядок абзацу відбиває наступний абзац, як у класичній книзі.

### 4.8 BodyTextFirst — Перший абзац після заголовка

```

Base:        BodyText
Відступ:     0  ← немає абзацного відступу (типографічне правило)
```

### 4.9 CodeLabel — Мітка мови над блоком коду

```
ID:          CodeLabel
Шрифт:       Consolas Bold, 7.5pt (#666666)
Фон:         #EBEBEB
Вирівнювання: Ліворуч
Відступ:     лівий 0.5 cm (283 DXA)
Відстань до: 12pt; після: 0pt
Рамка:       верх+ліво+право 1pt (#CCCCCC); знизу — немає
Наступний:   CodeBlock
```

**Вигляд:**
```

```

---

### 4.10 CodeBlock — Рядок блоку коду

```
ID:          CodeBlock
Шрифт:       Consolas, 8.5pt (#1E1E1E)
Фон:         #F8F8F8
Вирівнювання: Ліворуч (не по ширині!)
Відступ:     лівий 0.5 cm; правий 0.5 cm
Міжрядковий: Точно (exact) 11pt
Відстань до: 0pt; після: 0pt (крім останнього рядка блоку: після 12pt)
Рамка:       ліво  3pt суцільна #0078D4  (синій акцент)
             право 1pt суцільна #CCCCCC
             знизу 1pt суцільна #CCCCCC (тільки на останньому рядку)
             верх  — немає
```

**Вигляд всього блоку:**
```
╔════ C# ══════════════════════════════════╗
▐ using System;                            │
▐                                          │
▐ class Program                            │
▐ {                                        │
▐     static void Main()                   │
▐     {                                    │
▐         Console.WriteLine("Привіт!");    │
▐     }                                    │
▐ }                                        ╝
```
`▐` = синя ліва рамка 3pt; права і нижня рамки сірі 1pt.

## 5. Стиль таблиць

### 5.1 Загальні правила

- Таблиця завжди розтягується на повну ширину контенту (CW = 6122 DXA)
- Без порожніх стовпців-розпірок
- Колонки розподіляються рівномірно, якщо не задано інше
- Підпис **над** таблицею (стиль `TableTitle`), якщо є

### 5.2 Шапка таблиці

```
Фон:         #1A1A2E (темно-синій)
Шрифт:       Times New Roman Bold, 9.5pt, #FFFFFF
Вирівнювання: По центру (горизонтально і вертикально)
Padding:     верх+низ 5pt; ліво+право 6pt
```

### 5.3 Рядки даних

```
Непарні:     Фон #F0F4FF, шрифт TNR 9pt #1A1A1A
Парні:       Фон #FFFFFF, шрифт TNR 9pt #1A1A1A
Padding:     верх+низ 4pt; ліво+право 6pt
Вирівнювання: По лівому краю (числа — по правому)
```

### 5.4 Рамки

```
Зовнішня:    1pt суцільна #C0C8D8
Внутрішня:   0.5pt суцільна #C0C8D8
```

### 5.5 Широкі таблиці

Якщо таблиця має 4+ колонки і текст не вміщується:
- Зменшити шрифт до 8.5pt (Consolas для коду всередині)
- Або розбити на дві таблиці

## 6. Зображення

### 6.1 Розмір

```
Максимальна ширина:  408 px при 96 DPI (= 108 мм, вся ширина контенту)
Масштаб:             Пропорційний, зменшення якщо ширина > 408px
Менші зображення:    Не збільшувати
```

### 6.2 Розміщення

```
Вирівнювання: По центру
Відступ до:  8pt
Відступ після: 0pt (підпис іде одразу після)
Keep with next: Так (зображення не відривається від підпису)
```

### 6.3 Підпис

- Стиль: `FigureCaption`
- Формат: текст alt-тексту з markdown (без "Рис." — просто описовий текст)
- Розташування: під зображенням, по центру

### 6.4 Коли файл відсутній

```
[⬜ Діаграма: <alt-text>]
```
Сірий курсивний текст, легка пунктирна рамка, фон #F5F5F5

## 8. Спеціальні блоки

### 8.1 Підсумок (## Підсумок)

Зустрічається наприкінці кожного підрозділу. Блок із синьою лівою смугою і блакитним фоном.

```
┌─ Підсумок ─────────────────────────────────
│                                            │
│  • C# — мова програмування…               │
│  • .NET — платформа…                       │
│                                            │
└────────────────────────────────────────────
```

Реалізація: заголовок `SummaryTitle` + тіло `SummaryText` + списки зі збереженою лівою рамкою.

### 8.2 Примітка (> текст у md)

```
┌─ Примітка ─────────────────────────────────
│                                             │
│  Зверніть увагу: у C# string — це…         │
│                                             │
└─────────────────────────────────────────────
```

Жовтогарячий акцент, жовтий фон.

## 10. Що іде у `constants.js`

Єдине місце для всіх числових констант. Решта файлів імпортують звідси.

```javascript
// Розміри сторінки (DXA)
A5_W, A5_H, M_TOP, M_BOT, M_INN, M_OUT, CW

// Кольори (hex без #)
C.NAVY, C.DARK_BLUE, C.MID_BLUE, C.ACCENT, C.BODY, ...

// Розміри шрифтів (half-points)
SZ.TITLE, SZ.SECTION, SZ.SUBHEAD, SZ.BODY, SZ.CODE, SZ.CODE_LABEL, SZ.TABLE, ...

// Відступи (DXA)
IND.FIRST_LINE, IND.CODE_LEFT, IND.CODE_RIGHT, IND.LIST_LEFT, IND.LIST_HANG, IND.SUMM_LEFT

// Міжрядковий (multiple × 240)
LS.BODY   = 276   // 1.15
LS.CODE   = 240   // single / exact

// Розміри зображень (px at 96 DPI)
IMG.MAX_W = 408
```

## 11. Структура модулів (`lib/`)

```
constants.js   → числа та кольори (чистий об'єкт, без залежностей)
    ↓
styles.js      → Word-стилі для Document() (імпортує constants)
numbering.js   → конфіг маркованих і нумерованих списків
    ↓
images.js      → читання PNG-заголовку, масштаб, ImageRun
parser.js      → MD-рядки → блоки AST (чиста функція, без docx)
    ↓
renderer.js    → AST-блоки → docx Paragraph/Table/ImageRun
                (імпортує constants, styles, images)
    ↓
md-to-docx.js  → CLI: args, glob, читання файлів, збірка Document, запис
```

---

## 12. CLI-інтерфейс (план)

```bash
# Один розділ по glob
node md-to-docx.js "lectures/sections/01-*.md" -o "output/chapter-01.docx"

# Кілька файлів явно
node md-to-docx.js file1.md file2.md file3.md -o out.docx

# З явною назвою розділу
node md-to-docx.js "lectures/sections/02-*.md" -o out.docx --title "Розділ 2. Основи мови"

# Кастомна тека з ресурсами (PNG)
node md-to-docx.js "..." --assets "lectures/_assets"
```

**Автодетекція:**
- Назва розділу: з frontmatter першого файлу (`chapterTitle`)
- Assets: `_assets/` → перевіряє `../`: `../_assets/` → `../../_assets/`
- Output: якщо `-o` не вказано → `chapter-NN.docx` у поточній теці

## 13. Типові сценарії помилок і рішення

| Ситуація | Рішення |
|---|---|
| PNG відсутній | Placeholder: `[⬜ Діаграма: alt]` |
| Таблиця з порожнім першим стовпцем | Заміна `''` на `—` у шапці |
| Дуже довгий рядок коду | Відображається як є, Consolas адаптується |
| Рядок frontmatter у тілі | Пропускати все між `---` і `---` на початку |
| Нестандартний мову коду (```ps1, ```sql) | Маппінг у `CODE_LANG_MAP`, fallback = `Код` |
