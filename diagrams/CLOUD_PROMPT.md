# Промпт для хмарної сесії Claude Code: рисунки розділів 10–21

Скопіюйте блок нижче в нову сесію на claude.ai/code (репозиторій
`MrTomkaYurii/OOP-Tomka-CourseForHardCoders`). Одна сесія проходить усі розділи по черзі.

Промпт **відновлюваний**: після кожного розділу сесія пушить гілку, а повторний запуск із
тим самим текстом сам знаходить перший незроблений розділ. Якщо сесія обірвалася (ліміт
часу чи контексту) — просто запустіть нову з тим самим текстом.

Щоб прогнати інші розділи, замініть перелік у першому рядку та ім'я гілки.

## Перевірено

Скрипт оточення й рендер перевірено в чистому контейнері `ubuntu:24.04` (draw.io 31.7.0,
.NET 10.0.401): результат збігається з Windows-рендером. Відомі пастки Linux уже враховано:
`libasound2t64` для Electron і `--disable-dev-shm-usage` (замалий `/dev/shm` у контейнерах).
Не перевірено лише мережеву політику самої хмари: скрипт завантажує draw.io з GitHub
Releases і .NET з `dot.net`.

## Після сесії

Приходить один PR з гілки `diagrams/chapters-10-21`. Якщо сесія змінювала генератор
(`diagrams/generator/`), цю частину PR варто переглянути уважніше: зміна впливає на всі схеми.
